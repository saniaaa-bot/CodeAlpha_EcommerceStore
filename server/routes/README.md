# TechAlpha - Full Stack E-Commerce Store 🚀

A premium, dark-themed E-commerce web application built as part of the **CodeAlpha Full Stack Development Internship**. 

## 🌟 Features
- **User Authentication:** Secure Register/Login system using JWT (JSON Web Tokens) and Bcrypt.
- **Product Listing & Search:** Real-time search functionality to find gadgets.
- **Shopping Cart:** Dynamic cart using LocalStorage.
- **Checkout & Orders:** Users can place orders with shipping details (Address & Phone).
- **User Dashboard:** Customers can view their past orders and track their status (Pending, Shipped, Delivered).
- **Admin Panel:** A dedicated dashboard for Admin to view all customer orders and update their delivery statuses.
- **Responsive Design:** Fully responsive UI that works on desktops, tablets, and mobile phones.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Authentication:** JWT, Bcrypt.js
- **Tools:** VS Code, REST Client, Git & GitHub
